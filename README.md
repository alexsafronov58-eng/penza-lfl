# PENZA LFL — мобильное демо v0.4

Статический сайт для GitHub Pages. Матчи и новости — демонстрационные.

## Публикация с телефона
1. Создайте **Public** репозиторий `penza-lfl` на github.com.
2. Загрузите файлы **изнутри этой папки** в корень репозитория: `index.html`, `app.js`, `style.css`, папку `assets`. Не загружайте только ZIP: GitHub Pages не распаковывает его.
3. Settings → Pages → Build and deployment → Deploy from a branch → Branch `main`, folder `/(root)` → Save.
4. Откройте `https://ВАШ-ЛОГИН.github.io/penza-lfl/` через несколько минут.

На iPhone видео может требовать касания «Смотреть заставку». Для перехода можно нажать на зелёную кнопку на постере или «Пропустить».

Данные пользователей не хранить в GitHub Pages; для настоящих кабинетов потребуется backend.
